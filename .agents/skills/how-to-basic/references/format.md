# Response format

How every `how-to-basic` answer is shaped. Read this before composing the final response. Same fixed order every time.

## Precision rules

- Plain words come first. Jargon waits for a one-line definition, then gets reused without redefining.
- Facts land directly. Hype, emoji, and jokes stay out, while concrete examples carry the weight.
- Short stepwise sentences hold one idea each. Each abstract claim pairs with one concrete trace or number.
- Some behavior has no rule. It parks as an open question instead of getting a smoothed-over story.
- Five fixed moves run in order under the same headings every time. Responses stay comparable that way.

## The five moves

- First comes assumptions. A sharp contrast states what the system promises and what it never does, with data flow end to end.
- Base rules come second. Two to four exceptionless rules anchor the system, and each later behavior derives from exactly one of them.
- Third arrives the wider pattern. Named groups by job reveal one repeating shape, plus what changes together.
- Provenance follows fourth. The originator and the predecessor it reacts against appear, with the one design limit explaining its shape.
- The smallest build closes fifth. One minimal exercise hits every base rule at once, then basic scope and next unlocks get named.

## Verification checks

- A newcomer repeats the base rules without notes. Otherwise a rule gets cut.
- One current shape traces to a past choice rather than to logic alone. That frozen accident stays named.
- Ignored detail gets declared now. The deep dive that restores it gets declared too.
- Simple rules plus past accidents produce the observed behavior. Magic never explains anything.
- One common wrong belief falls. The exact rule that breaks it is the refutation.

## Against teach-me

- Single-shot grounding before building with a system the operator must touch now belongs here.
- Multi-round learning with digging and fading help and quizzes toward durable recall belongs to `teach-me` instead.
- Quizzes and cross-round fading never happen here. The mental model confirms in one sentence, then the build is handed over.

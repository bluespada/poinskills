# Teach Me

## When to activate
- Activate on teach me X, how X works, or explain X so I really get it.
- Skip direct answers, debugging, or build tasks unless teaching mode is explicit.
- Treat each request as underspecified until the slice and motive are known.

## Dig into what to teach first
- Never lecture first or assume the whole topic is wanted.
- Dig with short back-and-forth before explaining.
- Ask goal, wanted slice, prior knowledge, confusion, and use case.
- Narrow broad topics to one concept per round and confirm it.
- Ask one familiar domain for analogies, then start small.

## Explain in small honest paragraphs
- Teach one paragraph at a time and confirm before the next.
- Open hard ideas with one familiar demo plus a text prediction question.
- Reveal the outcome stepwise, then name the principle in one sentence.
- Probe accepted knowledge with why, how, and what-if chains.
- Refuse misleading analogies and state where each breaks.
- Name stopping points: what stays basic now and what unlocks next.

## Match method to knowledge type
- Label the slice memory, procedure, or concept before teaching.
- Memory: spacing plus tiny recall checks, not demo-first.
- Procedure: faded worked examples, removing steps as skill grows.
- Concept: demo plus prediction plus self-explanation.

## Fade help and guard efficiency
- Tier help: question, bigger hint, partial answer, then full explanation.
- Fade support and request a solo attempt before review.
- Stay concise first and cap probes at two before explaining.

## Problematize then space review
- When they get it, ask for another solution or formalized intuition.
- Close with one variant problem plus a delayed retrieval cue.

## Offer a quiz then use the question tool
- Offer a short scoped quiz after each paragraph and proceed only on agreement.
- Run it in the host question tool when available, else markdown one at a time.
- Ask one focused question at a time, allowing own-words answers.
- After each answer give what was right, what was missed, and correct reasoning.
- On decline keep teaching and re-offer later.

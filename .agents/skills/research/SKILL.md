# Research

## When to activate
- Activate on research this, gather evidence on X, or summarize X with sources.
- Skip when the user wants a direct answer from memory or code without sourcing.
- Treat every brief as a collection requirement until scope and depth are set.

## Direct the requirement first
- Restate the question in one sentence plus what a good answer contains.
- Fix scope: time window, geography, depth, and what stays out of scope.
- List 2 to 4 subquestions whose answers together settle the main question.
- Name what would change the answer before collecting anything.

## Collect like an open-source case officer
- Run the public-source cycle: direct, collect, process, analyze, report.
- Sweep OSINT first: official docs, datasets, reputable press, scholarly work.
- Add HUMINT-style moves adapted to the open: elicit from docs and debrief published interviews.
- Prefer penetration access like primary sources over fringe commentary.
- Log every source with origin, date, access level, motive, and track record.
- Keep collecting until subquestions stop changing, then stop and analyze.

## Verify before trusting anything
- Grade each item as fact, direct info, or indirect info with stated doubt.
- Demand corroboration: no single-source claim enters the summary as fact.
- Reexamine dismissed items when new facts cast them differently.
- Run competing hypotheses and keep the one surviving evidence, not preference.
- Flag recalled, ambiguous, or motive-tainted reporting with lower confidence.
- State confidence per claim as high, medium, or low with one reason.

## Explain like an undergraduate
- Open with a 2-sentence plain answer before any detail.
- Define each jargon term once on first use, then reuse it plainly.
- Teach one idea per paragraph in short stepwise sentences.
- Pair each abstract claim with one concrete example or number.
- Name limits plainly: what is known, unknown, and what unlocks next.
- Close with one takeaway plus one check question for recall.

## Cite every claim
- Attach one inline citation per factual bullet with title plus URL.
- Quote numbers with source, date, and sample or scope beside them.
- Never cite a claim the source does not directly support.
- End with a source list ordered by weight with primary first and press last.
